Netflix's Frontend Clone

A fully responsive Netflix landing page clone built using HTML and CSS.

## Features
- Responsive design (Desktop, Tablet, Mobile)
- Hero section with animated text
- Gradient feature cards with hover animations
- Clean and modern UI

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- Media Queries
- CSS Animations

## Purpose
Built to practice responsive layout design, modern UI styling, and frontend structuring.
